# LinkedIn Post Draft

I completed a hands-on Microsoft Entra ID and Azure IAM security lab for a fictional organisation, NovaTech.

The project focused on practical identity and access management controls, including:

- Identity lifecycle changes and leaver offboarding
- Least-privilege directory and Azure RBAC assignments
- SAML single sign-on configuration and troubleshooting
- Reader versus temporary Contributor access testing
- Sign-in and audit-log investigation
- Administrative monitoring and manual access review

The lab also documented real troubleshooting and tenant limitations rather than presenting an idealised result. For example, native Entra Access Reviews were unavailable in the tenant, so I completed and documented a manual access-review process.

I published the sanitized report, architecture diagram, and evidence screenshots here:

https://github.com/HARSH062001/novatech-entra-iam-security-lab

This project strengthened my practical understanding of Microsoft Entra ID, Azure authorization, identity governance, audit evidence, and secure offboarding.
