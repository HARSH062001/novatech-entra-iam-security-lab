# Resume-Ready Project Bullets

## NovaTech Identity & Access Management Security Lab | Microsoft Entra ID and Azure

- Built and tested a Microsoft Entra ID and Azure IAM lab covering identity lifecycle management, least privilege, SAML SSO, Azure RBAC, audit investigation, monitoring, offboarding, and access review.
- Configured role-oriented users, groups, directory roles, enterprise applications, Azure Storage, and subscription-level permissions; validated Reader versus temporary Contributor access and restored the least-privilege final state.
- Investigated sign-in and audit evidence, documented SAML ACS/Reply URL and NameID troubleshooting, and connected confirmed administrative activity to monitoring and alerting outcomes.
- Executed a leaver offboarding scenario by disabling the account, revoking sessions, removing residual group/application access, and validating the resulting state.
- Published a sanitized portfolio repository containing an architecture diagram, professional report, limitations, lessons learned, and 41 evidence screenshots.
